# Student Registration Form

A simple and responsive **Student Registration Form** created using **HTML and JavaScript**. The project includes client-side validation for student information and demonstrates the use of different HTML form elements.

## Features

* Enrollment number input
* Student name input
* Marwadi University email validation
* Password and confirm password validation
* 10-digit phone number validation
* Date of birth validation
* Address, city, state, and pincode fields
* Gender selection using radio buttons
* Branch selection dropdown
* Semester selection
* Division selection
* Multiple hobby selection
* Profile photo upload
* Terms and Conditions checkbox
* Submit and Reset buttons
* JavaScript form validation
* Alert messages for invalid input and successful submission

## Technologies Used

* **HTML5**
* **JavaScript**
* **Regular Expressions (Regex)**

## Form Validation

The form validates the following information:

| Field              | Validation                            |
| ------------------ | ------------------------------------- |
| Enrollment Number  | Cannot be empty                       |
| Name               | Letters and spaces only               |
| Email              | Valid Marwadi University email format |
| Password           | Minimum 6 characters                  |
| Confirm Password   | Must match the password               |
| Phone Number       | Exactly 10 digits                     |
| Date of Birth      | Cannot be a future date               |
| City               | Letters and spaces only               |
| State              | Letters and spaces only               |
| Pincode            | Exactly 6 digits                      |
| Gender             | Must be selected                      |
| Branch             | Must be selected                      |
| Semester           | Must be selected                      |
| Division           | Must be selected                      |
| Hobbies            | At least one must be selected         |
| Profile Photo      | Must be a valid image                 |
| Terms & Conditions | Must be accepted                      |

1. Clone the repository:


3. Open `index.html` in any web browser.

4. Fill in the student registration form and click **Submit**.
